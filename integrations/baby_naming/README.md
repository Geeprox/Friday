# 宝宝起名工作台

工作台由 Friday 家庭内网门户打开。「老公」用松墨绿头像，「老婆」用胭脂红头像。选好身份，再选「女孩」或「男孩」。两个方向分别找名字。手机用竖版收藏卡，桌面用横版。每个身份有三幅专属纹样，新名按洗牌顺序抽取；同一浏览器回到同一个名字时保留近期看到的卡面。

- 已有一组名字时直接开始看；暂时没有候选时点「请 AI 找名字」。点名字簿右上的设置图标进入二级页，可选默认的「6.1-Sol 高」或「Luna 低」。设置按身份保存在 NAS，更换设备也有效，保存无需重启。高档适合进一步探索，会更慢也会多用额度。每次开启新搜索才生效；一轮已开始时，另一人继续接用该轮。模型在 NAS 后台规划、造名和盲审。页面关闭后可以继续，回来会接上。
- 左划「不喜欢」、下划「待定」、双击「喜欢」。拖回原位再松手可取消。有效手势松手便开始离场，下一张先在后台准备，判断保存后接着显示。连接失败时原卡会回来，可以再次尝试。卡片下方有取名线索，三个按钮也可直接判断。刚才的判断可以撤销。需要明确否决时，在「我的记录」选「排除这个名字」。
- AI 找到能帮助下一轮搜索的对照时会安排选择题。对照题的答案只用于学习偏好。部分名字在隔天安排一次复看，第一次和复看冲突时保留待定。
- 双方积累了有区分度的新反馈后，工作台会在后台整理可能的交集和下一轮要验证的偏好。结果用于之后的查找，当前卡片可以照常看。
- 同一名字各自判断后才看到对方的判断。两人都喜欢时进「共同备选」，可展开读音和出处。分别按「我愿意用这个名字」，这个方向就可以先停，之后可继续找。

**两个人需要同时打开吗？** 不需要。每个身份的已打开任务、判断和确认都保存在 NAS。换设备后选回相同身份即可。免账密入口以家庭内网为信任范围；身份选择用于区分记录。

**不想看动效怎么办？** 打开系统的「减少动态效果」即可使用静态卡片；不支持 WebGL 的浏览器也会自动显示静态卡片。三个判断按钮始终可用。

**API 不可用怎么办？** 已审核的名字和已保存的判断可以继续使用。页面会说明本轮搜索为何中断，可以按提示重试。

**能查重名、办理登记吗？** 工作台显示可核对的原文和常见读音。重名、登记结果仍通过相应地区的官方服务核验。

部署与验证见 [NAS 部署](../../docs/baby-naming.md)。
