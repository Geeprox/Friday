# 本机画面复核

Friday 在骨骼跌倒检测之外，提供可选的本机短视频窗口复核。它使用
`mlx-community/Qwen3.5-2B-4bit`，适合先在 Apple Silicon、16 GiB 统一内存的主机上验证。
它按时间顺序分析四张图，不具备 VLX-Flow 的原生持续视频状态，也没有婴儿监护准确率验收。

## 开启与关闭

先完成 [本地视觉运行环境](deployment.md) 和摄像头配置。MLX 依赖已声明在
`local-runtime` extra，使用本地锁定依赖；Console 本身不会下载模型。
摄像头感知进程的 Python 环境也需要 `mlx-vlm==0.7.3`。

模型放在 `data/embodied/models/qwen3.5-2b-4bit/`，包含本地 tokenizer、processor、
chat template 和 safetensors。固定版本为
`674aaa7240b91e8012fcad5d791b7dfe5ba90207`。权重文件为
`model.safetensors`，大小 `1722271785` 字节，SHA-256 为
`713fe7e5d3c3965f7106b0d0ee17615f7869c23c8d327996df8c1196fbcf07d5`。
检查固定版本与文件摘要后，在同目录保存 `friday-source.json`：

```json
{
  "repository": "mlx-community/Qwen3.5-2B-4bit",
  "revision": "674aaa7240b91e8012fcad5d791b7dfe5ba90207",
  "weight_sha256": "713fe7e5d3c3965f7106b0d0ee17615f7869c23c8d327996df8c1196fbcf07d5"
}
```

进入「智能预警」，先开启监测，再开启「本机画面复核」。两个开关默认关闭；
查看页面或运行普通测试不会启动模型。没有清晰、新鲜、固定视角且场景配准稳定的画面时，
复核不会开始。暂停监测、隐私关闭、镜头切换、配准失效或策略更新，会清除对应窗口并取消请求。
关闭复核时，已存在的待查看事件仍保留在私有记录中。

## 性能边界

- 每秒最多采一帧，每个请求四帧，模型输入最长边 256 像素。
- 全部摄像头共享一个子进程、一个请求槽；两次提交至少间隔六秒，不积压请求。
  多镜头轮流复核，单镜头频率随镜头数量下降；最多保留八个镜头的短窗口。
- MLX 分配限制为 3584 MiB，缓存 64 MiB。这不是整个 Python 进程或统一内存的硬上限。
  冷启动要求系统报告至少约 5 GiB 可用余量，已加载时至少约 3 GiB；未知内存状态或高 CPU
  负载会暂缓。失败后按 15、30、60 秒退避。
- 单次请求十二秒超时，空闲六十秒退出。子进程锁避免多个视觉 worker 重复加载同一模型。
  其他应用仍会竞争统一内存，压力检查只提供保守准入，不保证多模型并行性能。
- Seek 和 MiniCPM-o 不随此功能加载。Seek 可做目标定位；当前内存预算下，先使用已有检测、
  人物框与追踪。没有通过 Mac 实测的 Seek 路径不会自动启用。

## 事件与证据

模型只允许返回普通画面、视野不足、疑似跌落、面部遮挡或快速搬动五类结果，以及短观察。
两个互不重叠的窗口出现同类结果后，才保存一条「画面待复核」记录和两段窗口的关键帧。
一分钟内同类记录去重。模型不能提供人物身份、严重等级或执行动作。

这些记录只进入人工复核，永不触发语音。原有骨骼时序跌倒检测与单设备播报策略保持独立。
呛奶、窒息、哭闹、打婴儿及用力过重等专门能力仍不可用；低分辨率、低采样频率会漏掉短动作，
面部遮挡观察也不能证明呼吸状态或照护意图。

全部推理离线，无云端回退。事件沿用私有 SQLite 和关键帧权限、容量、保留期与误报核对流程，
详见 [隐私说明](privacy.md)。停止监测不会自动删除已留档证据。

## 验证

纯软件回归使用锁定视觉环境：

```sh
data/embodied/runtime/bin/python -m pytest tests/test_temporal_review.py tests/test_embodied_safety.py -q
node tests/safety_console_fixture.cjs
```

实机模型验证必须单独使用合成或已授权素材，分别记录冷启动、热请求和 MLX 峰值。
合成图验证只能证明本机推理、协议和简单时序兼容性；实际照护场景的漏报、误报与提醒延迟需要另行验收。
