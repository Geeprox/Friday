# 隐私回看与事件证据

“回看”进入页面后自动恢复已配置的 NAS 连接并读取录像，默认静音播放最新片段。
每次只保护当前播放位置起的最多 30 秒；播放期间提前准备下一段，时间线可定位整条录像。
事件证据保留在“查看家庭事件”中，可核对来源、操作读回和录像引用。打开事件详情不会
发送设备动作或调用模型。NAS 自动恢复失败后才显示重试与登录入口。

时间相近或同组记录不等于因果。来源未记录原因、历史来源无法核对或外部规则不可见时，
界面会保留未知。设备报告与请求一致不代表物理效果已确认。旧来源和旧绑定的记录不会
自动关联到当前家庭的摄像头或规则。

## 保护预览

两个播放入口都只向浏览器提供已经完成的保护衍生文件。没有保护产物时不返回可播放
地址；不会回退到原片。原始 NAS 文件保持不变，临时衍生文件保存在本机私有目录中。

首次安装播放依赖：

先通过系统包管理器安装 FFmpeg（包含 `ffprobe`）：macOS 使用 `brew install ffmpeg`，
Debian/Ubuntu 使用 `sudo apt-get install ffmpeg`。Friday 只查找已安装且权限安全的工具，
不会自动下载或执行第三方安装脚本。基础家庭连接不依赖这些媒体工具。

```sh
uv sync --locked --extra privacy-playback
python3 scripts/archive_privacy.py status
```

默认模式是整帧马赛克，不下载或启动检测模型。选择性遮挡需要用户明确配置自己的
本地模型；检测器缺失、损坏、输出异常或画面判断不确定时，预览加强至整帧保护。
选择性识别可能漏检，不承诺所有私密场景的准确率。源音轨会保留，播放器默认静音；
视觉保护不会自动去除音轨中的个人信息。

当前支持原片单文件不超过 256 MiB、10 分钟，保护预览不超过 64 MiB、1280×720。每个媒体 owner
最多一个生成任务和两个衍生文件，生成最长 180 秒，单个衍生文件租约五分钟。录像连续播放每次最多 30 秒；任意定位
会撤销旧播放及预取，新的片段仍须完整保护后才能播放。事件引用入口保持原有时钟范围校验。所有视频帧均先处理
再编码；不采样跳过保护。停止、切换事件或房间、离开页面、来源变化和过期都会使旧预览
失效并回收；客户端取消准备会取消对应隔离进程。进程中断遗留的缓存由后续运行按私有
目录、锁和归属检查回收，主机断电期间不能执行删除。

## 可选的本地选择性遮挡

此路径使用固定 SHA-256 的 NudeNet 3.4.2 `320n.onnx`，可选配固定 Tiny YOLOv3
定位完整人体。权重及第三方检测实现不随 Friday 分发，CLI 不下载权重。NudeNet 的
[PyPI 元数据](https://pypi.org/project/nudenet/3.4.2/) 标注 MIT，而该版本 wheel
附带 AGPL-3.0 文本；配置前应审阅实际资产和随附条款，不能将 Friday 的 MIT 扩展到权重。

```sh
uv sync --locked --extra privacy-playback --extra privacy-model
python3 scripts/archive_privacy.py local-model \
  --model /absolute/private/320n.onnx \
  --person-model /absolute/private/tiny-yolov3-11.onnx \
  --accept-model-terms
```

工具只复制校验通过的权重到忽略的私有状态目录，写入 0600 配置和来源说明；不会加载
模型、读取录像或启动服务。省略 `--person-model` 时，检测到敏感区域但无法可靠归属人体
会整帧保护。配置在服务重新启动后生效，不热改已有播放租约。

默认源运行状态目录是 `data/homeplane/`。桌面实例使用本机 Application Support 下的
对应设置目录，操作该实例时通过 `--state-dir /absolute/private/state` 明确选择。
状态响应只报告配置和依赖，不把“已配置”当成识别能力已验证。

切回整帧模式：

```sh
python3 scripts/archive_privacy.py full-frame
```

## 软件验收

普通回归使用生成视频、合成事件和注入检测器，不启动家庭设备或模型。覆盖真实接口
响应进入界面、逐帧遮挡、音轨与时间、Range、撤销、取消、来源变化、缓存归属和原片
不变。模型兼容性验收须单独运行并写明素材范围；不以合成测试代替家庭场景准确率验收。
