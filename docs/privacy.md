## 游戏音效

家庭游戏可由使用者在当前游戏页主动开启本机音效，默认关闭。短音直接在浏览器内合成，不使用麦克风、播报服务或家庭音箱，不修改系统声音输出；暂停、来源中断、画面未就绪和页面隐藏会停止当前音效，离开页面会释放声音资源。游戏事件音不补播旧进度，也不加入原有无声游戏录像。启用操作会播放一声短提示，以确认本页声音已开启。

## 后台任务提醒

首页从原执行回执与单次任务时钟读取错过时间、连接或权限变化导致未执行，以及设备结果未确认的事项。查看提醒不会重跑任务。点击“已了解”仅在同一本机规则库保存该事项、原执行和规则版本的摘要关联；不会修改规则、授权或设备状态。任务改名后保留原执行时的标题，新一次异常使用不同标识，不会被旧的已查看记录遮蔽。条件未满足、手动接管和正常暂停不生成任务失败提醒。

提醒一次最多读取 64 项；执行回执及其标题沿用原有七天清理周期，回执过期不表示设备结果已确认。单次错过时间的已查看标记保留至对应配置改变；执行结果的已查看标记保留至对应回执清理。标记最多 1024 条，达到上限时拒绝新增，不覆盖其他记录。任务标题仍属于私有家庭数据，不进入诊断或公开材料。此链路的模拟设备与界面测试不构成真实设备效果验收。

## 家庭 KTV

本机 KTV 管理后台可按歌曲删除 Friday 管理的原曲与加工文件，并可选择同时清理 NAS。批量删除绑定预览修订，保护本场待唱、播放与制作任务；账户会话、用户个人原文件、工具和模型不属于删除范围。两端容量自动清理需在本机设置中开启；启用后删除空闲的管理副本。管理会话可控制房间和点歌，仍仅接受精确本机地址与同源写入，访客及电视密钥不能使用这些管理能力。

电视首次使用、更新和故障恢复保持暂停及麦克风静音；开启需新的明确用户动作、系统录音权限授权和当前房间控制状态。音频实现根据设备能力在内部准备，扫码页和声音设置不提供技术通道选择。
用户手动静音后，换歌、重唱、刷新与应用返回都保留选择。后台和暂停停止硬件采集，不将
用户选择改成静音；返回普通后台保持暂停，路由故障不会自行清除故障状态。
原始人声只经过系统本地音频通道，兼容路径采用有界内存混音，不写入录音文件、日志或 NAS。
厂商通道由独立、签名授权的守护进程持有，该进程没有网络权限；主进程不重复采集人声。
诊断只保留帧数、缓冲、峰值、削波与固定状态等聚合量，不包含说话内容或自由格式上游错误。

从 KTV 0.56 候选起，用户请求开启麦克风时，会在独立 `:wet` 进程建立语音保护观察器。
它通过厂商 USB 缓存入口读取有界内存 PCM，干声继续由独立守护进程持有；主程序不把干声
再送入软件返听。观察器与混响共用一路输入，关闭混响将湿声清零并保留保护观察；手动静音
保留会话，暂停、后台、失去租约或退出释放。观察通道的权限、身份、路由或新鲜度不满足时，
守护程序保持零增益；运行中观察器失联会锁定静音，不能自动恢复为无保护返听。

窄带风险分析只在本机内存进行。JNI、Binder 与诊断只传递固定标量计数、频点、保护阶段、
设定增益及故障码。PCM、完整频谱、声纹或说话内容不进入诊断，不写录音文件，不上传到 NAS。
自动保护按固定范围的厂商后级 EQ、增益衰减、最终锁静音执行；恢复需要新一次手动开麦。
只有完成的零增益/停止回执才确认静音，本地意图和HTTP回执不作为静音成功。

0.56/0.57 的厂商缓存钩子具有普通采集回退风险；0.58 移除观察器的该钩子与普通AAudio输入。
0.58新增的严格观察适配要求平台侧缓存桥，仅通过本机Unix内存包把已存在的缓存送到独立湿声进程，
不通过Friday的JNI/Binder控制接口传递PCM，不写文件或日志、不上传。平台进程与允许的两个应用UID通过内核身份
和私有配置验证，未知身份、错误代次、未绑定或过期会话都不能读取。宿主只绑定已加载且代码摘要
匹配的厂商对象；读端没有普通采集回退。该平台组件是新增安全链的实现要求，不是此前已通过用户听感验收的原厂干声直通的原始前提。当前实现缺少完整安全证据时保持麦克风关闭，不把另一条未经同等延迟验收的软件返听静默当作替代。普通设备的软件处理通过标准录音权限和实际路由运行。端到端延迟及误报/漏报仍需现场验收，
算法判断不作为真实反馈成因或物理静音的证明。

手机自动对拍由用户点击后申请麦克风，短时聆听电视音乐并在手机本机比较谱变化；没有音频
上传或声纹识别。结束、取消、关闭调音页与页面隐藏会停止采集。权限策略只允许本站申请
麦克风，仍禁用摄像头与定位；浏览器不支持或拒绝授权时保留手动同步。

KTV 0.57 协调候选把房间、命令与电视播放状态直接交给 NAS。电视使用独立密钥，歌曲
制作 Worker 保留自己的账号与管理凭证。交付清单只提供绑定歌曲版本和期限的媒体读取票；
电视和 NAS 缓存不能用该票调用 Mac 管理、账号或控制接口。固定媒体路径与私有来源校验
不会放宽为任意 URL 代理。选择 LAN HTTP 时沿用受控家庭局域网传输；HTTPS 配置保留
正常证书与主机名验证。

家庭身份、当前场次、在线状态与数据清理分开。暂停、暖场和断线不清歌单；只有明确结束
才关闭本场，之后按保留期清理。已加入访客可在本场内继续使用原凭证，二维码更新不会
撤销这些凭证；本轮没有新增访客时间 TTL。离线迁移工具只生成新的私有候选文件，不覆盖
已有家庭配置、NAS 数据库或连接密钥，也不会启动服务或设备。

耳边伴唱的原唱与同时间轴伴奏参考文件放在 NAS 私有目录，限定当前房间已加入访客与当前歌曲，执行完整性
校验并使用有界缓存。云盘目录与歌词缓存不会暴露上传地址、账号 ID、Cookie 或本机路径；
公开歌手与歌词匹配请求不携带账号会话。云盘原音频仍来自用户授权的上传文件。

鼓掌与喝彩使用随电视应用提供的固定 CC0 素材；手机只发送固定动作、序号与音量，不能提供
任意媒体地址或上传声音。过期命令不执行，退出和换房释放氛围音输出。

## 体感游戏画面

游戏页面只提交本局/当前动作示范的短期显示标识、序号、是否可见和素材是否就绪，不提交截图、人体关节或原始摄像头数据。服务端使用自己的时钟和短期窗口检查，最多保留本局当前动作的 8 个同时可见页面与 128 条页面标识，全部只在内存保存。关闭、隐藏、失去连接或素材不可用会撤回本页面的就绪状态；另一块有效的游戏屏幕可以继续显示本局。最后一块有效画面失联超过 2.5 秒时冻结进度，已得到的分数和关卡保留；恢复仍需原有玩家/画面检查和明确继续，不补算离开期间的动作。

动作关间加载示范时暂缓倒计时，保留原玩家绑定。同一局、同一模式的相邻动作可以沿用上一有效画面尚余的可见期限等待新回执，不刷新期限、不继承就绪资格，也不计算动作或倒计时。新关已受理的回执接管该期限；隐藏回执先到也会撤回继承的可见资格，另一块当前已就绪画面仍可继续。页面必须核对挂载示范与当前动作一致，上一动作的画布或就绪回执不能进入下一动作。

显示检查不赋予摄像头、模型、家居控制或身份识别权限，也不表示人正在看屏幕。已有本机摄像头隐私与动作源校验继续独立生效。当前验证覆盖合成动作、原 API 与浏览器中的页面衔接；真实电视显示、延迟、舒适度和识别准确率仍需验收。

体感游戏的电视舞台只向已登记电视提供当前局的游戏数据。专用凭据绑定电视地址，可用于当前舞台的显示回报、开局、暂停和继续。画面流不带摄像头图像、关节、身份、转写或设备状态。更换电视地址需更新私有配置。电视舞台不启动摄像头，也不取得电视墙、录像或设备控制接口的权限。

## 家庭狼人杀

入座、白天发言和平票发言时，主持人可取消或重新选择镜头对应。局中调整只作用于仍在场的座位。取消只解除指定镜头、会话与人物编号的对应。每次实际调整都会更新对应版本，入座阶段也更新房间版本。绑定和取消分别校验本局、对局版本、对应版本和请求编号。镜头恢复后，主持人确认新画面的编号才建立新对应。已对应给其他座位的编号无法重复选择。

选择镜头辅助后，本机主持人可在入座页点击「显示画面」，或在白天发言和平票发言时点击「调整座位」，读取已运行镜头的画面与同次采样的人物编号。图像和编号一起过期，切换阶段、界面隐藏或关闭显示时清除。接口只接纳当前对局的本机同源请求，传输大小与等待时间均有上限。公屏可显示公开的座位提示，镜头画面仅在本机主持端显示。图像、人物身份及转写内容不持久保存。编号由主持人用于人工对应座位，手机仍负责身份确认和投票。

手机身份和夜间选择留在当前对局的私有接口。按住查看身份，松开或离开页面时收起。
电视连接码须在两分钟内确认。当前主持端确认后，原电视标签页的随机凭据才可读取公屏和入座邀请。服务在内存中保存凭据摘要、当前连接和最近公屏读取时间，关闭房间时清除。
主持端通过被动读取本机接口清单发现手机入口中断。可用地址仅返回给本机主持端，局域网公屏不接收地址清单。新入口接通后，旧地址的请求无法继续读写本局，旧公屏凭据及座位恢复链接失效。玩家身份和选择仍留在同一个内存房间，找回座位的确认规则沿用原流程。
大厅有空座时，当前大屏凭据可在同一局域网入口读取房间号和手机二维码。二维码仅包含手机入座地址和房间号。满座、发牌或大屏失去连接时收起邀请，关闭房间后撤销大屏凭据。
首夜前，每部手机只确认当前凭据对应的座位。主持端和公屏只收到确认总人数。返回入座后，原身份和确认作废。
轮流发言时，当前座位可凭自己的手机凭据和当前版本结束自己的发言。公开状态包含座位、计时和发言进度，发言内容不经手机接口采集或保存。
结算后在原房间再开一局时，手机和大屏沿用本房间凭据。新局清除上一局的角色、选择回执和准备状态，旧入座版本的请求失效。关闭房间仍会撤销所有凭据。
在手机上选定行动和目标后，仍需确认提交。公共画面在座位上方显示当前阶段、倒计时
和主持提示。座位只在本局结束后显示已公开的身份。大屏插图复用随应用分发的游戏封面。

待确认的投票或夜间行动只在手机页面会话中暂存对局、座位、阶段版本及随机请求编号。
角色、行动和目标不写入浏览器存储。返回或刷新后，手机凭原座位凭据读取该编号是否
已记录，公屏不接收回执。服务只在内存保留本局最近 2048 条请求摘要，关闭房间时清除。

主持控制和摄像头座位绑定要求当前对局、版本与请求编号，旧页面不能推进新环节或关闭另一局。
重复指令只返回当前状态，不再次执行。服务只在内存保留最多 256 条主持请求摘要，
不将身份、行动或播报文本写入该重试记录。

主持播报与场景灯光分别推进。跨阶段时，灯光清理不延误下一条公共提示，扬声器清理
也不延误灯光恢复。同一路输出仍按顺序处理。暂停前尚未尝试发送的提示可在恢复后
播报。已尝试或结果不确定的输出不自动重播。灯光选择、切换与恢复依次执行，
重复恢复不会重复释放原状态。显式恢复还绑定请求时的对局和场景，在排队后、状态
读取后及实际发送前重新核对，旧请求不能操作新场景。

当前手机页面在提交入座前，将本局、座位、昵称及随机恢复编号暂存在当前页面会话，
用于回复丢失后继续确认同一次入座。编号不进入网址或公共画面；个人访问凭据保存后
清除恢复记录。入座回执仅在原标签页自动恢复。明确更换邀请或
房间后，本机不再重试旧待确认请求；已经占用的旧座位仍由主持人移除或随房间关闭。
服务器只在内存保留本局最多 128 条摘要，不保存明文恢复
编号或个人访问凭据，不按昵称或座位找回他人的访问权限。移除玩家和关闭房间仍会
撤销原凭据；旧恢复请求不能加入同短房号的新局。已核对本局上下文的入座请求共享
有界预算，支持十二位手机使用同一网络出口；未知房间仍使用原来的尝试限制。

换手机或关闭原页面后，主持端可为指定玩家发放短时恢复二维码。手机在本次标签页暂存
恢复凭据和用于重试的随机编号，凭据从链接片段读取后即从地址栏收起。主持端二维码
有效期两分钟，仅限一次交接。手机确认后撤销该座位的原凭据。公屏、普通邀请和房间号
不能读取恢复凭据，也不能查到任何玩家的私有身份与行动。

关闭先撤销手机和公共画面访问，并立即将房间报告为关闭，再等待输出和网关清理。
同一次关闭的重试不会关闭后来新建的房间。此边界不证明已提交的外部播报已停止，
真实扬声器、电视、灯光与摄像头效果仍需分别验收。

狼人杀启用镜头辅助时，只临时占用已经运行的主摄像头。占用绑定本局、当前 worker
及新鲜、稳定的画面；云台正在转动时不提供座位对应。占用期间暂停该镜头的自动
转向和家居手势控制，其他镜头继续按原设置工作，语音策略保持原有授权。
结束对局会释放占用；失联后占用在三秒内到期。开始、结束或到期会撤销旧的排队
转向和手势，恢复家居手势前仍需放下并重新做出动作。占用不改变持久巡视设置、
镜头隐私或采集许可，也不会启动新镜头、模型或改变米家镜头开关。

## 语音输出的生命周期

主持、语音答复和异常播报经同一 Speaker 入口，每个进程只接纳一个当前作业，并以
私有目录中不含内容的文件锁避免不同进程并发提交播报作业。取消后不会立即释放名额：
HTTP、合成子进程与临时文件均结束后才释放。连续切换环节也不会重复取消旧清理任务。
静音、交互过期、对局变化或输出目标变化会撤销尚未发出的内容，不形成无限播报队列。

HA 播报使用可取消、有大小上限的异步请求，不在执行器线程中留下迟到发送。每次发送
重新核对当前授权文件版本；短期访问令牌只在该传输的内存缓存，不覆写其他服务持有的
登录文件。系统语音合成仅处理本次随机命名文件，延迟启动和完成但未交付的结果仍由
原作业回收；不会按名称或年龄删除其他语音文件。

媒体播放器在合成后再次检查是否已被其他内容占用，并沿用设备当前音量，不自动调高。
异常提醒在准备及发送前，通过有界存储队列重新核对当前事件和监测策略；标记误报、
策略撤销或记录不可核对时，不再提交尚未发出的提醒。核对不读取事件画面或声音。
标记误报会保留本条提醒的播报撤销标记；随后更改查看状态不会恢复旧待播报作业。
外部播报已提交后发生撤销，结果保留为待确认，不把本机结束等待当作远端声音已停止。
HomePod 流绑定已选身份并持有独立连接。已提交给 HA 或远端设备的播放不能仅因本机
取消就宣称停止；不确定结果保留为未确认，不能据此认定已经听到声音。合成子进程和
静默适配器测试也不等同于系统 TTS、AirPlay、声学时序或主机异常断电验收。

## 录像回看与事件证据

从镜头详情打开回看时，服务依据用户保存的录像对应关系核对当前镜头与存储来源，只读取对应目录的列表。用户选择片段后，才准备保护播放。

回看只播放本机生成的短时保护预览，保留 NAS 原片。默认整帧马赛克；显式配置本地
检测器后可选择性遮挡，异常时加强保护。播放器默认静音，视觉保护不去除原音轨中的
个人信息。取消、来源变化和过期会撤销预览；临时衍生文件仅保存在本机受限目录。
配置、限额、模型许可和验收范围见 [隐私回看](privacy-playback.md)。

事件详情复用本机已授权的历史读取，不获取新权限。来源明确记录的因果、同组记录、
时间相近和未知原因分别展示；录像只提供经核对的摄像头与时间引用。打开事件不会
自动读取视频或操作设备。ARL 通信正常、历史缓存和身份/模型能力验证也分别表达。

## 照片编辑副本

照片处理复用既有 NAS 来源和有界读取，不新增登录、挂载或原件写入权限。
原图最多 64 MiB，只在内存与独立处理进程的管道中传递；不使用模型或上传云端。
输出移除原图 EXIF、位置、XMP 与注释，并重新生成 sRGB 色彩配置。
编辑方案审核与实际副本生成分别记录，副本不表示已保存到用户磁盘。
处理结果采用有界内存和短期本机下载入口，到期主动清除；撤销、来源变化和
审核过期后不再交付。完整限额、格式、许可与验收范围见[本机照片处理](PHOTO-EDITING.md)。

## 摄像头开关与暂停

自动人物跟随和宠物跟随使用当前镜头的目标框。视野确认后，同一目标连续两帧贴近
画面上沿或下沿，且方向一致，才可上下调整。目标同时靠近两条边时优先保住明显
更近的一侧，距离相近时优先横向。每次只发一个方向，发送前重新核对最新目标框、来源和镜头模式。转动后等
新视野稳定再判断。重建宠物追踪时使用新编号，多个动物重新入画时等待明确目标。
自动俯仰后视野持续受阻时，尝试一次反向调整，并暂避已经观察到受阻的相对角度。
声音复核按来源留档，转向依赖画面上的目标框。

云台转动前，从当前人物或猫狗目标框内提取的画面特征只在本机内存中短时保留。
使用画面对应时，两帧独立画面都确认同一目标后才继续跟随。特征不进入人物库、异常留档、日志或界面接口。

实时画面中点选跟随对象时，镜头把一张当前识别帧与同帧目标框交给本机界面。界面只使用临时编号，画面响应禁止缓存，八秒后清除画面及目标框。退出选择或切换到后台时也清除。选择凭据只在当前采集会话和镜头设置版本内有效。画面、临时选择和轨迹都在内存内处理，重启后恢复停留当前视角。连续看见未登记目标时，每台镜头最多每两秒尝试更新一次特征。特征不足时保留最近一份有效参考，期限从原始采集时刻起算，最多八秒。更换采集会话、切换模式或游戏接管会清除参考。

摄像头声音在采集子进程中保留分片的最早本机接收时间，并绑定当前摄像头与本次
采集会话。输入中断会丢弃未完成的声音片段；父进程拒绝过期、重放、格式错误及
来源不匹配的数据，不把旧片段重新标成刚听到的声音。诊断只保留固定状态和计数，
不保存原始声音。这些时间来自本机 SDK 的接收记录，不代表已经校准了摄像头的
物理采样时钟，也不提供声源方向。

多个镜头共享本机画面复核模型；阳性候选最多优先复核一次，然后继续轮转，避免
等待使两段画面无法在原时限内相互印证。每次仍只处理四张采样图，常规复核的两个窗口必须
不重叠，并核对本局来源、画面新鲜度与当前策略。镜头或策略撤销也会取消优先复核。画面复核只生成待查看记录，
调度与模拟留档通过不代表真实异常识别准确率。

趴卧复核默认关闭。选定镜头的实际采集来源与设置一致时，才使用原画面模型核对姿势。
单人轨迹只用于内存中的窗口关联。两段画面一致后，记录只包含本机关键帧、采集时间、
镜头和待复核类型，不保存轨迹编号、人名或模型自由描述，也不触发播报或设备动作。

开启画面复核后，快速搬动线索可使用同一已授权镜头内的两条短时轨迹。每台镜头最多
保留一个待提交的四帧窗口，六秒后过期。只将本机模型也支持的窗口完整留档，轨迹、
身份和模型自由描述不写入记录。事件由家人在原提醒详情中查看，无自动播报或设备动作。

已开启画面或声音复核时，正在分析、等待二次印证或待留档的稳定视角可暂缓该镜头的自动跟随与
单轮巡视。每个当前来源和操作意图最多停留30秒，每60秒最多一个停留窗口；候选变化
不能续期。手动定位、宠物模式、游戏保持、视野或来源过期以及策略撤销继续使用原有
边界。提交自动转向前会再次检查，不回收已经发出的外部命令。为避免视角重置后反复
争先，声音与画面调度各自在有界内存里保留最多8个镜头的最近调度时间；重置仍清除
该视角的输入窗口和候选，策略撤销清空调度时间。这不增加输入缓冲、模型并发或自动播报，也不提供
声源方向或婴儿照护专门识别。

开启监测后，镜头下出现符合跌倒确认条件的快速倒卧，或已进入留档阶段时，同一镜头
可以短暂停留，等当前姿态和后续关键帧。主副镜头在选定和发出自动转向前都核对
来源、会话和策略。每个来源和操作意图的停留最长八秒，每二十秒最多一个窗口，
与声音和画面复核各自的窗口分开。手动定位、隐私和游戏占用沿用原有规则。
策略暂时无法读回时，只有已准入的留档可继续短暂停留；新的确认仍需有效策略。
确认沿用已有姿态和帧时间。已观察到快速倒卧且同一轨迹仍可辨时，短暂缺失一处关节可等候完整画面。
缺失期间暂停计时，留档与播报继续使用原有策略和权限。

自动水平巡视和主动发起的两层巡视，在发送转向前都要取得同一镜头可配准的清晰画面。收到云台回执后，须有同一采集会话与背景基准的两次新画面证实预期轴向变化，才确认一步。单轮巡视遇到无法确认或更换来源时结束，本轮发送上限包含失败及结果未知的尝试。普通自动巡视沿用云台失败退避。

定时巡视默认关闭，按镜头显式开启。它只使用已有的、读回为开启的摄像头和原云台控制租约。关闭隐私或暂停感知后停止巡视，恢复后重新计时。选择停留、手动调方向或切换跟随模式时，镜头保存新的模式并撤销旧巡视指令。定时本身只在内存中保存计时与视角数。

比较使用遮除已识别人形区域后的本机背景配准，当前变换与时间留在内存。画面确认的证据范围是两次稳定视角的相对变化。物理角度和房间覆盖仍需现场验收。

本机声音和画面复核的子进程在取消启动、超时或关闭后仍由原作业回收，实际退出前保留
独占文件锁；重复取消不会让新进程抢占尚未释放的资源。锁文件保持为空，不记录音视频、
识别内容或人物信息。软件进程回收测试不证明实际模型性能、识别准确率或硬件关闭效果。

画面复核收到模型加载完成的明确回执后，才重新核对来源、策略与最新四帧并提交画面。
就绪前不发送画面；加载期间撤销或画面过期时不提交请求。启动与加载共用十二秒期限，
不会通过延长证据新鲜度来接纳旧画面。此私有子进程协议要求父、子程序使用匹配版本。

可选声音复核默认关闭，单独保存启用状态。开启后只接收已授权、同一采集会话仍有新鲜视频帧的摄像头声音。
云台转向或视觉识别中断时，仍可复核该会话的连续收音。最多为八台镜头各保留两秒内存窗口，本机 SoundAnalysis 分类器串行
处理，超时、资源不足、类别不支持或输入中断时暂缓。只有实际模型返回的已知类别
才参与判断；两段不重叠的声音一致后保存疑似声音记录，每段最多关联一张本机接收时段内的已有画面。原始声音
不写文件、诊断或事件数据库，不上传云端，不据此识别婴儿身份或自动播报。
暂停声音输入、暂停摄像头、切换来源或撤销设置会清除尚未留档的候选和已印证证据。
当本机词表明确提供婴儿哭声标签时，连续三段各两秒的同源证据可以标记为疑似持续婴儿哭声。
阈值尚未经过家庭样本校准，记录供人工核对声音和画面。

「异响后环视」需要单独开启。疑似异响保存后，来源镜头处于自动模式且画面无人时，可短时查看起始视角两侧，最多发送三次水平转向。每次转向由同源新画面核实。人员入镜、游戏占用、停止声音输入或撤销设置会结束异响环视。声音为单声道，留档和转向均不标记声源方位或发声者身份。关闭声音复核时会同时关闭异响环视。

核实的新视角最多在原提醒里保留三张画面，每个确认步骤最多一张。保存时再次核对采集来源、监测设置和声音输入。标记误报后停止往该提醒补画面。环视画面随原提醒保留和清理。

查看已存提醒可独立于实时监测。点击标有「回看」的关键帧时，回看区间以同一留档中的采集时间为中心。源镜头和录像对应关系须经原校验，所选录像继续通过隐私预览播放。打开提醒或刷新记录只读取本机记录。

多个镜头共享一个声音分类器。出现阳性候选后，优先复核该镜头一次。连续两段婴儿哭声
最多再取得一次优先复核，随后让给其他镜头。声音中断或额外复核超过等候期限时，只要原来源与隐私校验仍有效，就以原接收时间保存两段已印证的普通哭声。
复核仍要求互不重叠的声音；关键帧取自分类前已接收的同源画面，没有对应画面时只留事件记录。
连续婴儿哭声的相邻分析段最多间隔 0.4 秒，每台镜头仍只保留两秒音频。关闭候选镜头
会撤销其待处理复核，其他已授权镜头继续各自处理。该调度验证不代表真实识别准确率。

保存普通哭声后，后续满足三段条件的独立证据可单独保存为疑似持续婴儿哭声。先前提醒的关键帧及人工标记保留。新提醒只关联新的证据时间和关键帧，同源重复的声音提醒继续使用 60 秒去重窗口。

可选宠物跟随只在用户为该摄像头选择后，向已运行的本机视觉程序请求猫、狗检测；
不会因此启动摄像头、麦克风或云端识别。动物框及短期轨迹与人物数据分开，
不进入家庭成员身份、手势控制、体感游戏或照护告警。这里的猫、狗标签不代表
某一只宠物的身份。选择保存在该摄像头的本机方向偏好中；暂停、手动转向和
关闭镜头仍优先。原生程序不支持、结果过期或目标有歧义时，不据此跟随。

体感游戏会话保持所选主镜头的画面稳定：等待、校准、进行、暂停和结算期间，不发送
该镜头的自动跟随、宠物跟随、巡视或遮挡恢复转向。结束游戏后重新取得新鲜画面，
再恢复原有自动策略；手动转向和镜头隐私设置继续优先。游戏不因此停止已授权的
观察和异常感知，也不扩大其权限。主镜头尚未发送的家庭手势绑定原游戏修订，
切换游戏后不能重新生效；其他镜头和家庭语音沿用各自的输入范围。内部修订仅用于
本机连续性检查，不增加人物身份、音视频存储或云端数据。已经提交的外部动作不能
仅因游戏开始或本机撤销等待就声称停止。

游戏结束或手势输入重新启用后，需在当前镜头中先放松，再做一次动作，才重新触发
对应的家庭控制。每个绑定单独等待可见的放松证据；遮挡、丢失关键点、重复画面及
早于交接时刻的缓存画面不计入连续放松时间。此状态只存在于本机内存，不增加录像、
身份或云端数据；语音输入和其他镜头继续各自判断。该规则仍需真人体验和误触率验收。

已授权镜头的人脸计算由独立本机子进程承担。只在已授权画面需要身份采样时才按需加载
既有模型；查看状态不会启动模型。每个镜头只保留一份待处理的新画面，计算变慢时
覆盖旧请求，画面、手势和巡航不等待身份结果。进程总数最多八个，模型空闲三十秒
后释放；超时或缺少依赖时身份保持未知，恢复需重新取得新鲜证据。
传输使用有界内存和私有 socketpair，不新增整帧图片文件、网络监听或云端请求。
已有候选人脸头像与模板仍按原有私有存储和登记规则保存。
暂停、来源变化和退出会撤销身份缓存及未完成的登记请求，迟到回复不进入新会话。
检测框重叠、轨迹离开或连续标记变化时，立即撤下对应的缓存身份。低分辨率画面
也可触发撤销。人脸回执与排队登记要再次核对当前轨迹。
最近看见记录只有与当前镜头、会话、人物轨迹及新鲜身份结果一致时，才显示为仍在场；
已保存的人物资料和最近看见历史保留。模型准确率与真实负载、延迟仍需单独验收。

镜头没有空间标定时，只使用当前画面中的骨骼、背景配准和人物轨迹，不生成户型、
家具、摄像头安装点或人物地面坐标。首次观察的参考画面只在内存中使用；只有明确
保存标定时才保存对应参考图和标定文件。旧版未记录手动确认的粗略标定保留为编辑
候选，不自动用于空间投影；文件损坏时保留原文件并继续基础人物识别。游戏的左右
移动和人物座位指认可使用画面坐标，不要求用虚构的地面坐标代替缺失标定。

米家的手动镜头开关和睡眠场景优先。Friday 后台取流、自动重连、人物识别和游戏
不会打开已关闭的镜头；旧版本保存的“自动打开摄像头”许可也不再生效。需要画面时，
先在米家打开对应镜头，Friday 才会重新接入。

短时断流时，后台保留本地采集的重连窗口，过期画面停止用于识别和控制。画面恢复后，
断流前尚未发出的语音操作已失效，注视也需要重新积累。采集会话终止时撤销该会话的
画面、识别和控制输入。清理异常时，后台等待旧采集进程确认退出后再按原模式重试。
每次重新接入都读取镜头开关，主动停止会取消重试。

在“摄像头”页或“设置 → 连接与隐私”中选择“暂停摄像头感知”，会保存暂停状态并
停止 Friday 的摄像头画面、声音输入、人物和动作识别。关闭窗口或重启 Friday 不会
取消暂停，打开游戏或预览也不能绕过它。选择“恢复摄像头感知”后，只接入米家中
已开启的镜头。此开关不改变米家自身的录像设置；要让设备镜头关闭，请使用米家的
镜头开关或睡眠场景。Friday 不强制把睡眠与关闭摄像头绑定。

“家中提醒”读取同一个后台监督器的恢复状态；读取页面不会启动新的监测进程。
“重试连接”只提前唤醒已经获准且未暂停的监督器，不改变摄像头感知、互动或镜头
开关。请求绑定当前策略版本；暂停前的旧请求不能恢复采集，重复重试受间隔约束。
只有重新读到运行状态后，页面才显示监测中；收到重试回执不等于恢复成功。

镜头已开启且摄像头感知已启用时，Friday 可以默认接管。接管前会保存该镜头当时的
巡航、人物跟踪、宠物跟踪、人物特写开关及当前收藏位；接管期间暂时停用原厂跟踪，
正常停止、隐私关闭或异常退出后恢复接管前的配置，不把这些设置永久改为关闭。
镜头关闭时不转回收藏位，也不发送开启镜头的指令。

恢复使用每台摄像头的独立文件锁和持久租约。独立监护进程通过专属管道检测采集进程
退出，包括强制终止；服务重启时也先回收未完成租约，再允许接管。恢复失败会保留
原始配置并重试，只有属性读回匹配后才标记完成。断网、设备断电、主机断电或所有
恢复进程被终止时无法保证即时恢复，需等网络、设备和 Friday 恢复运行后完成回收。
这些保证针对接管时保存的配置；不会猜测旧版本已经遗失或被覆盖的历史配置。

## 手动空间标定

打开编辑器时，标记、配准结果与参考图来自同一份不可变画面快照，不从持续更新的画面
另取参考图。每路最多保留四个内存编辑引用，十五分钟后失效；镜头来源或转动版本变化
也会撤销引用。提交时逐字节核对对应参考图，旧引用不能保存到新的镜头上下文。

只有用户保存标定时才保留参考图。配置和参考图放在摄像头私有目录的同一个版本文件中，
写入前完成本机独立进程校验，再核对编辑时的服务、来源和转动版本，最后原子替换。
初始化、普通画面和识别过程不自动保存标定。已有分离文件保持原样；存在新版文件时
只读取完整且校验一致的新版，不将旧参考图拼接进损坏的新配置。

校验或写入超时会终止并回收所属进程；调用者断开不会取消已经接纳的保存任务。
退出时，进程回收、可能提交后的运行时重载和临时文件清理仍由独立任务持有。
提交结果无法确认时不报告已保存，会撤销旧空间观察并从完整的持久版本重新加载。
只清理本次随机租约、创建时间和内容前缀均匹配的私有临时文件；未知或不安全路径
保持原样。校验和提交不经网络，也不输出参考图、标记名称或底层错误详情。
这些合成进程中断验证不等同于主机断电、不可中断文件系统故障或真实空间精度验收。

主、副摄像头的空间配准、位置计算与可见性检查由各自持有的本机子进程处理，当前帧
仅经有大小上限的私有管道传递。初始化和单帧运算分别设时限；超时或来源撤销后终止
所属运算，确认进程回收后才释放名额，失败重试逐步退避。空间结果不可用时继续视频，
撤销空间输入并暂停依赖它的游戏，不沿用旧结果。该边界不代表所有视觉运算都已隔离，
也不代表真实帧率、延迟或空间精度已经验收。

## 异常观察与留档

家庭异常观察通过有界后台队列留档，不在摄像头的画面、游戏或动作处理循环中等待
SQLite。最多八台镜头各保留一份最新待处理观察；较新的观察替换尚未处理的旧观察。
策略缓存过期时不继续接纳新的异常判断或图像；写事务取得锁后会重新核对策略版本与镜头会话。
暂停、来源切换和退出先撤销待处理输入；已经接纳的历史事件仍按原有保留规则管理。
新鲜度使用原始画面接收时间，排队或处理完成不会将旧画面标成刚刚看见。
身份标签读取变慢时，会再次检查身份时效，过期身份不会用于具名提醒。

已判定的疑似跌倒及完成印证的声音、画面复核使用同一留档队列，最多 32 项、
64 MiB 关键帧。声音和画面合计最多占用 8 项、8 MiB，等候写入时优先保存疑似跌倒。
已完成复核即可释放识别通道，其他镜头可以继续分析。来源仍连续、新鲜且策略未撤销时，
可在采集后 20 秒内重试本机保存，保留原始采集时间。复核仅排队事件信息与关键帧，
不会重新执行识别、缓存原始声音、操作设备或补发播报。同一次事件和后续关键帧使用固定记录标识核对，
提交回执不确定时不会生成另一条事件。到达重试期限后只回读这一事件的本机元数据，区分
已经保存、记录缺失、画面不完整和结果尚未确认；不读取 NAS 或原始视频。
云台转向后，同一摄像头的原采集会话须持续提供有效视频帧，才可继续写入已确认事件及其原视角关键帧。新视角从新的观察开始。
暂停、来源更换和退出会撤销这些待处理项。暂停声音输入也会撤销尚未保存的声音记录，
恢复声音输入不会重新接纳这批记录。在途存储调用仍持有其实际私有数据与预算，
直到工作真正结束，不能因取消等待就把资源当作已经释放。

存储工作由单个有界执行器串行处理。取消和退出会等待实际工作释放资源，不能以
取消了等待者代替数据库操作已经完成；预览或异常留档的清理失败也不能跳过摄像头
服务的停止。诊断只提供固定状态和计数，不输出人员名称、原始声音或私有数据库详情。

可选场景检测在独立本机子进程中按需加载现有模型，画面仅经有大小上限的匿名管道传递。
模型初始化和单帧检测有独立时限；超时或来源失效会终止子进程，确认回收后才释放
运行名额，失败重试逐步退避。服务状态不触发模型加载。镜头转动、暂停、会话和来源
上下文变化都会使旧结果失效；缓存沿用原始接收时间，内部来源信息不会混入场景对象。
这些边界适用于正常持有服务生命周期的进程，不代表已证明主进程被强制杀死或系统
不可中断 I/O 时的回收，也不代表场景模型、空间配准或异常识别的实机准确性已经验收。

## 发布审计

`python3 scripts/audit_publication.py` 扫描 Git 文件清单中的私有文件、个人主目录路径、
常见凭据、JWT、邮箱、硬件地址和未审阅二进制；输出文件位置，不输出命中的秘密。
维护者可提供忽略目录中的 `--private-patterns` JSON 字面量列表，额外核对自己的身份、
地址、设备与凭据。生成扫描报告放在 .artifacts/。

公开前还要对秘密扫描器、发布源码、可达 Git 历史、分支、标签、Release、issue/PR
附件和 CI 日志分别审查。当前文件被删除不等于历史被删除。私有研发历史保留在私有
仓库，公开仓库从审阅后的源码创建干净提交；不上传旧历史、工作区备份和现场截图。

自动检查不能保证发现所有个人信息。发布报告应写清实际检查范围与剩余限制，不能
用“零命中”声称任何环境、所有历史或所有硬件均已验收。
