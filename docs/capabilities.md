| 镜头感知恢复 | 原生识别子进程故障时只恢复识别，保持仍有效的采集连接。实时预览继续读取新画面，自动动作及异常判定等待有效识别。镜头关闭后撤下画面 | 主副镜头的原采集循环以合成读写超时、异常回复和恢复帧验证。真实设备的恢复时长与识别准确率仍待实测 |
| 镜头回看 | 从镜头详情打开该镜头的录像，按已保存且当前有效的录像目录对应读取列表。日期筛选保留镜头范围。选择片段后进入保护播放 | 使用合成目录、原录像 API 和保护播放路径验证。真实目录配置、录像读回和原生播放仍待验收 |

| 镜头巡视 | 摄像头详情可开始或停止一轮巡视。单轮巡视先平视，再降低视角横扫，最后抬回。人在本镜头或其他镜头中时，选定镜头仍按路线巡视，待复核的异常优先停留。每步以同一来源的两次新背景配准确认方向，最多预留十二次请求。详情显示当轮已确认的视角数与结果，关闭实时画面后仍可停止当轮。遇到视角无法确认、来源更换或游戏占用时结束当前路线 | 原主副镜头控制循环覆盖有人在场时的十步路线与异常留档。合成 API 覆盖新一轮、断流停止和过期请求。真实云台步幅、低纹理场景和房间覆盖待验 |
