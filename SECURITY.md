# Security

Do not put credentials, household exports, private logs, images or device IDs in
public issues or pull requests. Use a private GitHub security advisory when
available. Include a minimal synthetic reproduction, affected revision and fixed
error codes rather than raw account/session material.

Friday's Console is a local service. Do not expose its port directly to the
Internet. See docs/privacy.md for data storage, optional network paths and release
audit boundaries. A secret scan cannot guarantee the absence of all personal data.
